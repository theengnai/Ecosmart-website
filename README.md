## Getting Started

This project uses [TanStack Start](https://tanstack.com/start) with Vite, React 19, and Tailwind CSS v4, managed via [bun](https://bun.sh).

```sh
bun install
bun run dev
```

To build for production:

```sh
bun run build
```
